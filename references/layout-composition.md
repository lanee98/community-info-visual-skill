# 排版与可读性规范（版式构成 · 栅格 · 可读性 · 插画指令）

> 本文件是**唯一的排版规范**：版面骨架、栅格与间距、字号与对比度、图标与文字/卡片组的关系、插画指令，全部收在这里。
> 解决两个已确认的通病：①**通篇等宽横条堆叠**——所有信息一栏一栏往下排，像表格不像海报；
> ②**插画缺失**——版面全是文字块，没有空气感，插画也没有承担"形象提醒"的职能。
> 本文件提供 10 种版面骨架（B1–B10，选一种起步，可复合）+ 插画生成指令模板。信息筛选先行（见 information-filtering.md），版式是筛定内容的表现形式。

## 0. 画布基准（先锁死，再谈其他）

**所有尺寸、字号、间距都以一套固定基准画布为准，不随软件/环境/代理改变。**

| 项 | 规定值 |
| --- | --- |
| **基准画布** | **1600 × 2000 px（4:5 竖版）** —— 设计比例锁定为 4:5，任何软件的默认尺寸都不许覆盖它 |
| **默认输出纸型** | **A3**（297 × 420 mm，社区张贴最常见尺寸）；按 1600px 画布换算 ≈ **137 PPI** |
| **字号基准** | 各层级字号按**画布宽的百分比带**锁定（见 §4.2）：**L1 5.5–6.5% / L2 2.4–2.8% / L3 1.5–1.9%**（1600 画布等效 **88–104 / 38–45 / 24–30px**）。**带内取值由 D 级决定**（D1 取大、D2 取中、D3 取小）；**全图绝对下限 15px**；**出带须用户确认并留痕** |
| **字体链** | 中文 `'Microsoft YaHei' → 'Noto Sans CJK SC' → 'PingFang SC' → sans-serif`；英文 `'Segoe UI' → 'Helvetica Neue' → Arial → sans-serif`。命中即用，全图同一链（见 §4.6） |
| **换尺寸时** | 若确需其他画布宽（如 1080 或 2400），**百分比带自动换算**（这正是它优于固定像素值之处），比例仍为 4:5 |
| **A4 情形** | 若用户明确要印 A4（≈194 PPI），全图最小字号须提到 **≥ 17px** 才过 6pt 线（绝对下限 15px 只在 A3 下成立，见 §4.2 印刷换算） |

> 为什么先锁这个：换软件/换电脑产出不稳，第一根因就是**画布尺寸与字号表没跟过去**。画布 + 字号表写死，尺寸一致才有可复现性。
> 为什么字号用**百分比带**而非固定像素：固定像素在换画布宽时会整体偏大或偏小（且没人会记得手算）；百分比带让字号跟着画布走，换纸型/换比例自动成立。**带内不是随便取**——由 D 级（信息密度）决定取哪一头，见 §4.2。

## 1. 版式硬条款（违反任何一条即返工）

1. **禁止通篇等宽横条**：全海报不得由同宽度的横向条块自上而下堆完。横条列表最多作为局部模块（如服务点列表区），必须与至少一种其他形态（插画区/大字区/色块区/网格卡区）组合。
2. **主视觉区按 D 级定占比**：4:5 画布上——**D2–D3（信息较多）：主视觉 ≥ 40%**，版面紧凑但信息区不许挤掉空气感；**D1（信息较少）：主视觉 ≥ 65%**，插画是版面主角（信息区收成 2–3 个大块）。任何 D 级下，主视觉都不得用"纯色块 + 单个太阳/图标"的敷衍组合顶替。
3. **字号 ≥ 3 级对比**：全海报至少存在 3 个明显字号档位（L1 主标题 / L2 组标题 / L3 正文，各档取值见 §4.2 百分比带），且相邻档位倍率 ≥ 1.5。只有一级字号的版面等于没有层级。
4. **关键词图形化**：每页至少把 1–3 个最重要的词/数字"图形化放大"（超大数字、色块衬底、描边字），它们是居民 3 秒扫视的锚点。
5. **分区有边界**：区块之间用色带、留白或几何形状明确分割；相邻文字块垂直间距 ≥ 字高 × 0.8。
6. **视线动线完整**：版面要能按 "主视觉 → 主标题 → 行动区 → 详情区" 的顺序被扫读；用大小、颜色、编号引导，不依赖阅读自觉。
7. **形态按内容选，卡片框可选（硬条款）**：并列信息点的形态由内容决定，**卡片框不是必需品**——①并列同类短条目（步骤、服务点、注意事项、清单）→ 竖列排布（每项：编号/图标 → 短标题 → 短说明）；②单条长句的警示/提醒/导语 → **通栏条**；③两个权重相近的分区（如"何时注意"与"该做什么"）内容量都不大时 → **并排双列**，互相填补对方的横向空缺。**卡片框按密度取舍**：
   - **D1–D2（信息较少）**：可用卡片框（圆角矩形边界），边界带来秩序感；此时"组标题 / 卡间距 / 卡内左对齐"按框度量。
   - **D3（信息较多）**：**去掉卡片框**，改用**留白 + 组标题 + 左对齐文字栏**分组——去掉边框线，把空间还给信息呼吸。此时分组与间距按**文字块的视觉边界**度量（组标题与其下文字块的距离、文字块之间的呼吸间距），不再有"卡间距"这个量。
   - **不变的三条语义约束（无论有无框）**：每组必须有组标题（条款 10）；行距 ≥ 列距的等价节奏；文字共用同一条左边界。**框是可选皮肤，分组结构是必留骨骼。**
   - **通栏条例外口径**：通栏长条只允许三种用途——主视觉横幅、警示/提醒条、面板容器；**成图中"一条信息占满整宽"的横行 ≤ 2 处**。竖列项数 3–6，超过 6 项改两行网格（无框时即两行文字块）。
8. **并排双列对齐（硬条款）**：两个分区并排时，两列**顶线对齐、底线对齐**——第一项（或第一张卡）的上边缘与最后一项的下边缘各在同一水平线上；高度不足的一方把富余高度**均摊进各项/各卡**（不许只在底部堆空白）。**有框时**卡内文字随卡高垂直居中或顶部对齐；**无框时**各文字块按基线节奏对齐、两列节奏一致。同时禁止"右侧大空缺"：任一分区若留下 ≥ 版面 1/4 宽的连续空白，必须与相邻分区并排或改为拉通栏。
9. **图标间隙（硬条款，全部以图标高度 h 为基准倍数）**：
   - **图标 ↔ 同行文字**净距 ≥ 0.4h；图标与文字构成一个"单元"，单元内紧凑、单元之间放松（亲密性原则）；
   - **图标 ↔ 图标**（同组相邻）净距 ≥ 0.5h，不同组之间 ≥ 0.8h——两组图标共用一个区域时靠间距分组，不靠"挤在一起"；
   - **图标 ↔ 所在容器边**（卡片/色块/条带内边缘）≥ 0.5h，图标不得贴边或压在卡片圆角上；
   - **同组图标同尺寸、同轴线对齐**（同一水平中线或同一垂直轴线），间距等距——"看起来差不多齐"不算齐，成图后逐组目测 + 像素抽查；
   - 图标间隙不足时**先缩图标再缩间距**，两个都到下限还挤 → 回版式删块或换骨架，不许靠图标互相重叠硬塞。
10. **组标题与栅格节奏（硬条款，来源：用户对成稿的实测修改——下半版信息组曾因缺组标题而"不自解释"）**：
   - **每组必须有组标题**：≥ 2 个同语义信息项成组（服务点、行动准则、注意事项等）时，组上方必须有一行**组标题**，用完整语义概括这组"是什么 / 何时 / 何地 / 提供什么"（如"清凉服务点开放位置时间及提供的配套措施服务"）——不许让读者靠编号、颜色或插画徽章自行推断分组含义。**卡片框有没有都成立**（无框时组标题就是唯一的分组信号，更不可省）。组标题是独立文字层级：深色（主色/墨色）加粗，字号介于主标题与卡片关键词之间，左对齐贴版心边距，末尾不加标点。
   - **邻近性归组**：组标题与它所属组的间距 ≤ 它与上一组间距的 1/2——标题"贴下不贴上"，间距本身就是从属关系的声明。
   - **栅格等距**：同组信息项多行排布时**行间距 ≥ 列间距**（"横松竖挤"即返工），行列各自等距；**组间空隙 ≥ 组内间距 × 1.5**——分组靠"标题 + 加大间距"双重信号，不靠肉眼猜。**有框时按"卡间距/卡内边距"度量，无框时按"文字块视觉间距"度量**（以文字基线的净空为准）。
   - **卡内/项内左对齐网格**：一组文字的多行（标题/说明/标签）**共用同一条左边界**——文字列不得因为"第一行有编号/图标"就把后续行推回容器左边，形成左右跳动的锯齿边缘。编号圆/图标与首行垂直居中，文字整体构成一条垂直线；各组的文字左边界、组标题与版心边距也应逐一盘点（来源：用户裁定"文字和文字之间最好向左对齐"）。

## 2. 版面骨架库（十选一起步，可复合）

> 每种骨架都标注了适用密度与信息气质。第 3 步方案构思时**选定骨架并写一句话理由**，与风格选择（visual-style-library.md）同时进行：风格管"皮肤"，骨架管"骨骼"。

### B1 主视觉主导型（来源：沪上新章城市共创主视觉）

- **形态**：顶部超大标题 + 大幅插画占版面 40–50% + 侧栏/下部信息卡阵列。信息卡是"小岛"，插画是"大陆"。
- **适用**：D1–D2；有强主题氛围可以插画化的传播（社区形象、服务主题、活动氛围）。
- **要点**：插画与信息卡用同一色系串起来；信息卡内部仍按层级排，不许卡片等大排满。

### B2 插画叙事型（来源：社区健康讲座招募双联海报）

- **形态**：插画不是背景而是**叙事者**——场景化人物插画穿插在文字块之间，演出"这件事怎么做/做了什么样"；文字块用色块标签分段。
- **适用**：D2；行动示范、活动招募、亲和向主题。最适合"插画即提醒"的路线。
- **要点**：插画里的人物动作必须对应真实信息（瑜伽课就画拉伸动作）；插画下方紧跟对应文字，图和文不许各说各话。

### B3 拼图色块系统（来源：万科社区年度系列）

- **形态**：不规则大圆角色块（像拼图咬合）分割版面，色块内是"超大关键词 + 小注释"，照片/插画嵌在色块缺口里；中英文双语标签贴在色块边缘。
- **适用**：D1–D2；系列化传播（多主题统一模板）、年度盘点、成果展示。是"大小对比"教科书。
- **要点**：每张海报只讲一个词（趣·自然 / 趣·创作）；数字必须超大处理；色块 2–3 色循环，不超过 4 色。

### B4 手账网格杂志风（来源：龙湖超级社区体验季系列）

- **形态**：纸质感浅底 + 手绘涂鸦元素（箭头、胶带、贴纸、描边小图标）+ 网格卡片；标题做"拼贴混排"（大字+手写体+括号强调）；信息用编号 ①②③ 挂在网格上。
- **适用**：D2–D3；权益说明、招募清单、多板块活动预告。高密度下的呼吸感方案。
- **要点**：手绘元素风格统一（同一套线条粗细与颜色）；编号视觉明显；涂鸦是路标不是噪音，每页涂鸦元素 ≤ 8 个。进阶形态见 §5 工艺 8（手绘关联层）——词块间用手绘箭头连成关系网、小插画装异形窗格。

### B5 图形化数据叙事（来源：向涛社区"治理密码"版面）

- **形态**：大号数字色块（1/3/4/5）承载体系结构 + 胶片条/丝带形照片带分区 + 明确的 "02/06" 序号标题系统；标题层级三段式（主标/副标/导语框）。
- **适用**：D2–D3；工作汇报型展板、成果数据展示、体系解读。
- **要点**：数字即视觉主角——体系数字放大到 80pt+；照片带统一裁切高度；每段照片带配 3 行以内说明。

### B6 竖列流程卡系统（来源：工作汇报流程图模板）

- **形态**：并列信息点排成一排等宽竖列卡，卡内自上而下 = 编号圆牌 → 标题色块 → 说明文字；列底可加**阶段带**把卡片分组（如"筹备阶段 / 执行阶段"），阶段带只做分组不携带新信息。两种变体：编号悬于列顶外（流程感强）、编号嵌卡内 + 卡高渐变（时间推进感）。
- **适用**：D2–D3；步骤流程（1→2→3）、多服务点并列、分级清单、时间轴类信息。是"信息点竖列化"硬条款的标准实现。
- **要点**：列宽均分、内容异构时卡高随最长内容取齐；每卡文字必须完成"竖排压缩"——说明控制在 2–4 行，超了先压缩文案（见 information-filtering.md）再扩卡；阶段带颜色与卡顶编号同色系；列间距 ≥ 卡宽 × 0.04。
- **边界**：B6 是并列短条目的默认解，不是唯一解——两个内容量不大的分区并排能互相填补横向空缺时，优先并排双列（硬条款 7③、8）；单条长句仍用通栏条。判断标准是"这条信息以什么形态被读得最快"，不是"哪种形态更整齐"。

### B7 编号章节卡系统（来源：AMI 智慧电表科普长图）

- **形态**：顶部主题区三分——主题大标题 + 副题色带 + 大主视觉物件（产品/装置居中），左右可挂数据模块或地图小模块；中部 3–6 张**编号章节卡**（大编号悬垂在卡角外）；底部城市剪影/场景延伸带收尾。
- **卡内形态随内容变（本骨架的灵魂）**：对比型信息 → 卡内左右双栏对比（红✕/蓝✓注记）；流程型 → 图标链 + 箭头；操作型 → 界面/手势演示；数据型 → 图表。**相邻卡片的内部布局不得雷同**——卡外形统一（编号+标题带+圆角框），卡内布局是信息类型的函数。
- **适用**：D2–D3；多板块科普、服务告知、产品/系统解释。服务类告知的主力骨架。
- **要点**：编号是贯穿锚点（章节卡编号 ↔ 卡内注记编号同一系统，见 §5 工艺 1）；每卡说明 ≤ 3 行，压不进就回筛选流程删，不许缩小字号硬塞；章节卡标题带用同一色系循环（≤ 3 色）。

### B8 路径导览型（来源：Volksbank 合作社体系图）

- **形态**：一条蜿蜒路径/道路作为版面脊柱，路径上 3–6 个**编号站点**（等轴测或扁平小景），底部一排编号说明卡与站点一一对应；可配右上角图例/分栏表模块。
- **适用**：D2；流程导览、服务体系、"一条线讲清楚"类主题（服务半径、办事流程、年度历程）。
- **要点**：**编号双出现**——场景站点编号圈与底部说明卡编号同字体同色，视线可在两层之间来回跳；路径粗细与颜色全图统一，站点沿路径均匀分布；说明卡与站点按编号水平对齐；图例表列头 ≤ 4 列，超出拆两块。

### B9 大数字锚·情境网格（来源：KOSAF 七大行动指針海报）

- **形态**：超大数字（主题的关键量词：7 条 / 5 步 / 3 处）占据标题区半壁，与标题构成视觉锚点；下方网格排布 3–8 张**情境卡**，每卡四件套：场景插画 + **对话气泡（口语例句）** + 结论粗句 + 灰色细注。
- **适用**：D2–D3；行为准则、注意事项 N 条、分步指南。亲和向告知的首选。
- **要点**：
  - 气泡里写"居民会说的话"（"出门前要断电呀！"），不写书面语——气泡是情境的灵魂，删掉它卡片就退化成图标+文字。
  - 结论句 ≤ 14 字、加粗；细注 ≤ 2 行灰色小字（对比度仍须达标）。
  - 网格卡内部结构完全一致——**这里是形态统一的合法例外**：网格情境卡的重复是节奏感，不是同质化（与硬条款 7 不矛盾，它约束的是"信息块"形态，B9 的重复是设计语言）。
  - 大数字锚颜色 = 全图强调色；数字若来自母本数据（如"7 项注意"）须与母本核对。

### B10 满幅插画型（来源：单主体形象主视觉与图底一体海报通用范式）

- **形态**：**整幅海报就是一幅插画**——主视觉占版面 ≥ 70%（上不封顶），信息文字直接排布在插画的留白与安静区上。两种变体：
  - **图底一体型**：插画铺满画布（如一件大主体物居中撑满画面），文字沿四周环带与主体负空间排布，可局部与图形穿插咬合；
  - **留白环抱型**：单一有机形态的插画主体居中，四周大面积纸底留白承载信息；可用**竖排侧注**沿画布边缘走（侧注只放 L3 装饰性/详情级文字，不放 L1/L2）。
- **适用**：**仅 D1（≤ 5 块）且服务告知型亲和向**（一句话主题、单服务告知、社区形象）；D2 及以上禁用——信息块会把插画压死，"满幅"名存实亡。
- **要点**：
  - **留白前置是生死线**：生图提示词必须写明留白区位置与面积（顶部环带/两侧竖带/主体四周），文字只落在预留浅色区与低纹理安静区；生成后若找不到干净落点，重生成而不是硬压。
  - 文字不可避免压到插画纹理时，加 ≥ 70% 不透明底板或同色系描边粗体——可读性红线在 B10 里**不豁免**（这是它与艺术海报的分界线）。
  - 主标题仍是全图最大字、落在最安静的位置，3 秒测试照常执行；L2 行动层（时间/地点/电话）必须横排、高对比、落在常规视线终点（底部环带优先），不许竖排、不许变形、不许被图形穿插切割。
  - 文字与图形允许"咬合"（单词嵌进插画空隙、字母绕主体排），但只限装饰性文字与外语副题；中文关键信息不参与咬合。
  - **应急警示型慎用**：警示依赖条块高对比结构，满幅插画稀释警示强度；用户点名要 B10 时须在方案里写明可读性补偿（警示条加底板、警示色不参与插画调和）。
  - 复杂度仍按 §3.0 三判据执行——满幅不等于复杂，"一个大色块物体居中"照样是敷衍组合。

## 3. 插画生成指令（AI 插画规程）

> 插画不是装饰，是**形象化的提醒**：一张"老人在树荫下喝水"的插画，比一行"请注意补水"传达更快也更暖。D1/D2 密度、亲和向主题（健康、服务、清凉、社区活动）默认带插画；D3 或严肃警示主题可减插画但保主视觉区。

### 3.0 插画复杂度标准（先校验再生成，过简即返工）

**主视觉不允许"色块 + 一个太阳/一个图标"式的敷衍组合**——那种画面居民扫一眼就忘，也撑不起 40%/65% 的主视觉区。三条判据，生成前自查、验收时复查：

1. **元素量判据**：主视觉插画至少含以下之一——
   - **人物场景型**：≥ 2 个人物（或 1 人物 + ≥ 2 组道具/动物），人物有明确动作与互动关系（递水、搀扶、锻炼、遛狗），道具与主题强相关（清凉伞、水壶、电风扇、急救包）；
   - **场景全景型**（等轴测/鸟瞰）：≥ 3 栋建筑或功能分区，其中 ≥ 2 处内部有可辨识的活动（人物、家具、设备细节），建筑有细节层（门窗、招牌形状、屋顶差异）；
   - **条幅叙事型**：主体（人物或标志物）+ 背景层（建筑/山川/城市轮廓）+ 空中层（飞鸟、云、飘带）三层齐备，任意两层不得是纯色空白。
2. **层次判据**：画面有前/中/后三个深度层——前景主体大而清晰，中景支撑元素，远景氛围层（剪影、色带、纹理填充）。全部元素挤在同一深度 = 过简。
3. **细节密度判据**：主题相关的小元素（工具、衣物花纹、植物、器物）自然分布于画面，但遵循工艺 7（三层次色彩）——细节用中低饱和度，不抢主体轮廓。

**三种 validated 参考类型（生图时对号入座选一种，整张海报只用一种）**：

| 类型 | 画面特征 | 适用 |
| --- | --- | --- |
| **扁平人物场景插画** | 矢量扁平风人物，造型几何化但姿态生动，道具与动物细节丰富；3–4 色块面 + 少量纹理 | D1–D2 亲和向主题（防暑、健康、活动）；B1/B2 骨架 |
| **等轴测社区全景** | 建筑剖面/半剖面，多栋功能建筑 + 内部活动人物，细节密度高但排列有序 | 服务告知型（社区卫生站、服务站、综合服务体导览）；B8/S11 |
| **条幅叙事插画** | 横向或纵向条幅构图，主体居中，背景建筑/山河层次 + 空中飞鸟等填充层，色彩分层递进 | 主视觉横幅、收尾带、跨栏过渡区 |

- **反例清单（出现即返工）**：一个太阳 + 纯色块；一个温度计悬在空白中央；三个圆圈图标当主视觉；AI 生成的"模板感"城市天际线剪影无任何活动细节。
- **复杂度与可读性不冲突**：细节丰富 ≠ 杂乱——主体动作轮廓仍须大而清晰（见 3.3），文字落点仍须预留浅色区。

### 3.1 插画决策（先答三问再生成）

1. **演什么**：这张插画要演出哪条信息？（必须能指到信息清单里的具体条目；答不出来 = 纯装饰，删掉或换内容）
2. **放哪**：在骨架里的什么位置、占多少面积？（B1 大陆区 / B2 穿插区 / B3 色块嵌口）
3. **和文字什么关系**：插画邻近的文字块是否就是它演的那条信息？（图文相邻，不许图文分离）

### 3.2 提示词模板（生图用，按槽位填写）

```
【风格】扁平矢量插画 / 手绘水彩质感 / 等轴测（与主风格一致，整张海报只用一种；按 §3.0 三种参考类型对号入座）
【场景】<具体场景：社区广场/树荫下/家中窗边……>
【人物】<谁 + 什么动作 + 什么状态：老人坐在长椅上喝水擦汗，表情放松>
【细节】<按 §3.0 复杂度标准写足：≥2 人物或 ≥3 建筑、道具清单（遮阳伞/水壶/宠物）、前景-中景-远景各是什么、空中层元素（飞鸟/云/飘带）>
【构图】<在版面中的角色：下方横幅场景 / 右侧竖条场景 / 大面积主场景，主体偏<左/右>，<上/下>部留出大面积干净的浅色天空或空白区域>
【色彩】<与海报色系一致：<蓝青渐变/暖黄绿>色调，低饱和背景色块>
【负面】画面中绝对没有任何文字、字母、数字、水印、标志；人物不出现恐怖/病态细节；不出现真实机构标识；画面不得是"单一符号+纯色块"的极简敷衍构图
```

- **留白前置**：构图槽位必须写明留白区域——文字要落在插画预留的浅色区上，这是"空气感"的来源。
- **人物规范**：人物动作 = 信息内容（演出来）；人群多样性（老人/儿童/户外工作者）与受众构成对应；人物风格全海报一致。
- **生成后三查**：①无文字残留；②水印位置（生成图角落常有"AI生成"水印，裁切构图时预先排除）；③色调与海报色系不冲突，冲突则调色或重生成。
- **多插画时**：同一海报的多张插画必须同一风格、同一色调、同一人物比例——一次提示词锁定风格描述后逐张复用，只改场景与动作槽位。

### 3.3 插画与可读性

- 文字永远不直接压在插画纹理上：落在预留浅色区，或加纯色/半透明底板。
- 插画内的图形细节在小尺寸（打印 < A4 观看距离）会糊掉，关键动作轮廓要大而清晰。
- 严肃主题（灾害、事故、疾病）插画克制：不画笑脸 IP、不画夸张搞笑动作，可用场景+符号（雨伞、医药箱）代替人物戏剧化。

## 4. 可读性规范（字号 · 对比度 · 用字 · 双语）

> 公共信息海报的阅读环境是走廊、宣传栏、电梯口、展厅入口——行走的、匆忙的、视力不一的、以及不同语言的受众。本节把"看得清"变成可检查的条款，并**与 §0 画布基准、§1 栅格条款配套使用**。
> 依据：WCAG 2.1 对比度标准。
> **两层效力**：**第一层（对比度、最小字号、双语等价）任何题目永不豁免**；**第二层（风格化排版偏好）按调性取用**。

### 4.1 阅读速度测试

社区海报是"路过媒介"，测试在最终成图上做（缩小到手机约 6 cm 宽模拟远观）：

| 测试 | 要求 | 执行方法（谁测、怎么测） |
| --- | --- | --- |
| 3 秒测试 | 远距离 1 秒内识别主题（这是什么服务 / 什么通知），只看 L1 层 | **真人扫视，不是 AI 自查**：成图缩到手机 6 cm 宽，交给没看过设计稿的人看 3 秒，问"这是说什么的" |
| 10 秒测试 | 知道该做什么（核心行动条目或时间地点可读完） | 同一真人看 10 秒后复述"要做什么 / 什么时候" |
| 30 秒测试 | 找得到详情（地点、时间、电话、流程） | 同一真人看 30 秒后指出地点 / 电话 / 流程在哪 |

**语义项由人判定**：上表三问，以及"图文搭不搭、字号舒不舒服"这类判断，**机器断言测不了**——必须由真人看图裁定，并写进验收记录（谁测、怎么测）。这正是 SKILL.md 第 5 步"确认门 ③"要拦的东西。

### 4.2 字号表（第一层，永不豁免）——按画布宽百分比带

**基准画布 1600×2000（4:5），A3 输出（≈137 PPI）。字号写成"占画布宽的百分比带"，不是固定像素值**（理由见 §0）。

| 层级 | 占画布宽 | 1600 画布等效 | 说明 |
| --- | --- | --- | --- |
| L1 主标题 | **5.5%–6.5%** | **88–104px** | 全图最大；唯一允许用的装饰性字体 |
| L2 组标题 / 关键行动标题 | **2.4%–2.8%** | **38–45px** | 各信息组标题、警示标题；居民最先要抓到的信息 |
| L3 详情/正文 | **1.5%–1.9%** | **24–30px** | 行动条目、时间地点、详情、说明的正文 |
| 全图绝对下限 | — | **≥ 15px** | **用户规定**：任何文字都不得低于此值 |
| 英文对照 | ≥ 同级中文的 80% | — | 英文不是"小字附录" |

**字号执行口径（带内取值 + 出带留痕）**：
- **带内取值由 D 级决定**：**D1 取大**（信息少、字可舒展）、**D2 取中**、**D3 取小**（信息多、限量承载）——同一张海报的三档**同向取值**（全取大或全取小），不许一档取大、另一档取小。
- **出带须用户确认并留痕**：带是安全区，不是牢笼。用户若明确要求更大/更小（如"字再大点"），照办，并在验收记录写"用户覆盖 + 覆盖值 + 原带值"三要素（见 SKILL.md 第 0 节"用户裁定优先"）。
- **绝对下限 15px 不可覆盖**：任何层级、任何密度、任何用户要求下，文字都不得低于 15px；塞不下时回第 2 步删减或合并内容，不是继续缩字。
- 相邻层级字号倍率 ≥ 1.5（与硬条款 3 一致），不许"一级到底"。
- **跨环境口径**：百分比带天然随画布宽换算；换画布只须确认画布宽，字号带自动成立。**同一层级在不同密度的海报里字号不完全相同——这是设计意图（带宽 88–104px），不是违规。**

**印刷最低字号换算（6pt 线，打印前必查）**：

> **字号(pt) = 字号(px) × 72 ÷ PPI**，其中 **PPI = 画布宽(px) ÷ 打印宽(inch)**

| 印刷尺寸 | PPI | 6pt 线对应 | 说明 |
| --- | --- | --- | --- |
| **A3（297mm 宽）** | ≈ 137 | **≥ 12px** | **本 skill 默认输出纸型**；绝对下限 15px = **7.9pt**，过线 |
| A4（210mm 宽） | ≈ 194 | **≥ 17px** | **15px 在 A4 只有 5.6pt，不合格**——印 A4 时全图最小字号须整体提到 ≥ 17px |

- 编辑/委托前先问用户印刷尺寸（或按 A3 默认并留痕）；**同一张图按 A3 合格、按 A4 可能不合格**，不能只说"最小字号 13px"而不给 pt 换算。
- 验收记录里写明：全图最小字号 px 值 + 换算后的 pt 值 + 假设的印刷尺寸。
- **两道线取更严者执行**：屏幕可读（上表）与印刷 6pt 线，谁的换算结果大用谁。

### 4.3 对比度（第一层，硬性条款）

- 正文文字与背景对比度 ≥ **4.5:1**；大号文字（L1 主标题层级，≥ 88px @1600）≥ **3:1**。
- 禁止文字直接压在高纹理照片/插画上：加 ≥ 70% 不透明度的纯色/柔化底板，或使用带描边/投影的粗体字。**照片/插画作底时尤须注意**——素材饱和度与复杂度越高，文字越必须落在底板或预设留白区。
- 检查方式是对最终成图取样测量（文字色 vs 其实际背后背景色），不是检查设计稿里"用了深灰色"。
- **符号字符禁令**：⚠ → ① ✕ 等特殊符号字符在常用中文字体（宋体/微软雅黑）中常缺字形，成图后会渲染成"豆腐块"。装饰符号一律用代码手绘（三角形、圆牌、对勾路径），不直接打字符；确需字符时，必须在通道 B 看图时逐个检查是否有方块缺字。
- **混排字体禁令**：中英混排的字符串（含中文的"每日 10:00-20:00 开放"这类）必须用**含中文的字体**渲染，不可套用纯英文字体（Arial 等不含中文字形，会渲染成豆腐块）。
- 警示信息用高饱和强调色时，确认色盲可辨：红色预警不单独依赖红绿色差，同时用图标/形状区分。

### 4.4 图标规范（与文字、容器的距离）——并入排版规范

图标是排版的一部分：**它和文字的距离、和卡片的距离、和相邻图标的距离，全部按硬条款 9 的 h 倍数执行**（h = 图标高度）：

- **图标 ↔ 同行文字**净距 ≥ 0.4h；图标与文字构成一个"单元"，单元内紧凑、单元之间放松（亲密性原则）。
- **图标 ↔ 图标**（同组相邻）净距 ≥ 0.5h，不同组之间 ≥ 0.8h。
- **图标 ↔ 所在容器边**（卡片/色块/条带内边缘）≥ 0.5h，不得贴边或压在圆角上。
- **同组图标同尺寸、同轴线对齐、间距等距**；成图后逐组目测 + 像素抽查。
- 图标 + 文字双编码，图标永不单独承载关键含义；图标含义贴近期生活经验（水杯=饮水，太阳=高温）。
- 图标间隙不足时**先缩图标再缩间距**，两个都到下限还挤 → 回版式删项或换骨架。

### 4.5 用字与正文排版禁令（通用，不区分受众）

以下条款对所有题目一律生效，与 §4.2 字号表、§4.3 对比度同属硬性要求：

- **正文排版**：行距 ≥ 1.4 倍；段落**左对齐、不用两端对齐**；每行 ≤ 20 个汉字（超出则调栏宽或精简措辞）。
- **认知负荷**：一屏一个主任务；**行动条目数量按 SKILL.md 第 2 步的"行动条目数量规则"执行（默认 ≤4 条，≥5 条须人工确认，锁定母本优先）**——本节不再另立条数上限，避免与筛选规则冲突。
- **用字禁令**：禁用斜体、艺术字正文、细字重（≤ Light）、低饱和灰字、密集小图拼贴。
- **不得靠小字承载信息**：常见失败是主视觉极强而时间/地点变成蚂蚁字——任何信息都不许以"缩到看不清"的方式塞进版面（超量时回第 2 步筛选，见 information-filtering.md）。

### 4.6 双语版式与字体链（第一层）

- 英文版独立排版，套用同层级结构；英文换行按**词**断行（不得按字符切出 "confusio n"），出现孤词大间距时调整栏宽。
- 中文海报上的英文小注不得小于同级中文的 80%，且对比度同标准。
- **字族**：中文无衬线为主（黑体系），英文用同气质无衬线；正文不用衬线体混搭无衬线标题以外的花哨组合。可用衬线/书法体做**标题**（如公告类），但正文仍回无衬线。
- **字体链写死（跨机器一致）**：中文 `'Microsoft YaHei' → 'Noto Sans CJK SC' → 'PingFang SC' → sans-serif`；英文 `'Segoe UI' → 'Helvetica Neue' → Arial → sans-serif`。**命中即用，全图同一链**——不许各块各选一款，也不许靠"机器上装了什么都行"。
- **版式容错（防"字体换了、版面静默崩掉"）**：文字块一律**不定死高度**（弹性容器）——字号定，容器高不定；渲染后由页内脚本**自报**每个文字块的 `scrollHeight / clientHeight / lastBottom`，断言"无溢出、内容底边在预算内"。换机器换到别的字体时，行高/字宽漂移会被当场暴露，而不是悄悄被裁掉。
- **交付说明披露实际渲染字体**，验收记录留一行（字体链 + 命中款，见 references/production-spec.md）。

### 4.7 验收记录与像素取证

把时间测试结果、对比度实测值、字号表逐项写入验收记录。**实测不达标就是不达标，不能以"设计上已考虑"替代检查。**

对最终成图做像素采样验证时，遵循以下条款（来自停电海报双语验收的实测教训）：

- **双语版必须按各语言真实几何分带采样**。中英标题字号不同时（如 100px/83px），下游所有版块的 y 坐标整体偏移（本例差 17px）；用同一条固定 y 带跨语言采样，会把 A 版的坐标带错套到 B 版上，产生"楼宇像素比 0.86""EN 有白字"这类假阴性/假阳性。正确做法：y 带由同一份布局代码按各语言真实字体度量计算得出，而不是手抄一组坐标。
- **白色类检测容差收窄并排除纸底色**。纸底色（如 #F7F9FC）与纯白的距离在宽容差（≥12）下会被判为"白色"，把纸面空隙误计成白字像素。白色检测容差 ≤ 8，且先把已知背景色从样本中排除。
- **回显不可信时，验证只认两样东西**：对 PNG 直接做像素统计（颜色计数、分带采样、mtime 对比），以及用 Read 工具直接看图。文本回显（命令 stdout、路径列表、甚至同一文件的两次文本读取）都出现过损坏，不能作为"已验证"的依据。
- **对比度修复走闭环**：常数加深 → 重渲染 → 三检复跑（通道 A 逐字 + 通道 B 参数/成图 + 像素取证确认旧色消失、新色上版）。只改参数不复跑三检，等于没修。

## 6. 图文结合工艺库（九条，来自 validated 参考的共性提炼）

> 这些工艺是"设计感"的具体来源——它们既约束后制排版的画法，也写进生图提示词的构图槽位。方案构思时（SKILL.md 第 3 步）按骨架勾选要用哪几条，验收时按勾选项检查。

1. **编号贯穿**：编号在"场景元素"与"说明区"双出现（站点编号圈 ↔ 底部说明卡编号），同一字体同一色，观众可来回跳读。B7/B8/B9 通用。编号必须与母本条目一一对应，不许装饰性编号。
2. **卡内形态随内容变**：相邻卡片的内部布局按信息类型选——对比型双栏、流程型图标链、操作型界面演示、数据型图表。卡外形统一、卡内布局是信息类型的函数；连续两张卡内部布局雷同即同质化事故。（硬条款 7 在卡片内部的延伸）
3. **气泡引语**：口语例句用对话气泡承载（"出门前要断电呀！"），比陈述句更具体、更有亲和力；气泡底色与全图强调色一致；每卡 ≤ 1 个气泡；气泡文字 = 母本口语化改写时先向用户确认。
4. **引线标注**：点线 + 端点圆点把场景中的关键元素连到统一注释列（图标头 + 短标签 + 两行说明）；引线不交叉、不压文字；注释列与场景等高起步、逐条对齐。适合"症状/要点/部件"型解释。
5. **路径即动线**：道路/河流/序号线等连接元素做视线导轨，站点沿路径排列；路径终点放主题物。路径是结构不是装饰——删掉路径后信息仍完整，但阅读顺序会乱，这才算用对了。
6. **纹理填充层**：小花、云朵、飞鸟、剪影等小元素填充空隙——同一套形状语言、≤ 一层、密度上限是"不遮掩任何主体动作轮廓"；空隙本来就少的版面不加。
7. **三层次色彩**：大面积低饱和底 → 中面积中饱和元素 → 小面积高饱和强调。强调色只给信息（人物衣物、关键词、编号、图标），不给纯装饰；全图强调色 ≤ 1 个 + 相邻色系底。
8. **手绘关联层**：手绘箭头、连线、分支把相邻词块连成"关系网"（思维导图式），小插画装在圆形/异形窗格里，配手写体短注记——适合"多要素关系"与亲和向科普。约束：线条全图同一粗细同一颜色；连线只表达母本里真实存在的关联（能指到来源条目），不许为填空乱连；手写体只用于注记级文字，L1/L2 关键信息仍用正文黑体。
9. **蒙版主体 + 漂浮注记**：照片/插画主体经形状蒙版（像素块、圆形、有机形）抠出，置于纯色场（常用深色底）上；编号小方签漂浮在主体四周，引出贴近对应部位的短注记——适合"单主体多要点"的服务/设备/场所解释。约束：深色底逐项实测对比度（白字 ≥ 4.5:1，见 §4.3）；小方签做路标（编号与注记一一对应，同 §6 工艺 1 的双出现规则）；蒙版形状全图统一一种，不做多种蒙版混排。

**收尾带（附加工艺）**：版面下缘用城市剪影、地面延伸或色带收底，避免内容在画布边缘突兀截断；收尾带不携带新信息、不抢主视觉区面积。
