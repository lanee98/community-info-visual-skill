# 生产规范（渲染路径 · 导出链 · 稳定性断言）

> 本文件解决一件事：**"出图"这一步不能靠执行者自选**。文字后制、导出 PNG、跨机器复现——每一步都要有确定的路径和可断言的判据。
> 适用：所有执行环境档位（见 SKILL.md 第 0 节"执行环境三档"）。

## 1. 渲染器

- **Chromium 系内核**。Windows 上**推荐系统自带 Edge**（免安装，避免"装浏览器"本身成为环境变量）；macOS / Linux 用等价 Chromium 内核（Chrome / Chromium / Edge 均可）。
- **硬性标准是"渲染确定性"，不是"用哪个软件"**：只要满足第 5 节的稳定性断言（两次独立渲染像素差 = 0），任何等价内核都合规。**具体链路是推荐实现，工具可换、标准不变。**

## 2. 导出链（HTML → PNG）

1. **HTML 侧**：页面根元素固定为**所选取向的基准尺寸**（竖版 `width:1600px; height:2000px` ／ 横版 `width:1920px; height:1080px`）；`@page { size: <宽>px <高>px; margin: 0 }` 与之同步；`-webkit-print-color-adjust: exact; print-color-adjust: exact`（否则背景色、插画底色会被打印引擎吃掉）。
2. **HTML → PDF**：`<edge> --headless --print-to-pdf=<out.pdf> --no-pdf-header-footer <in.html>`。
3. **PDF → PNG**：`pypdfium2`（pip 可装、无系统依赖），`scale = 96/72`，输出**精确基准像素尺寸**（竖版 1600×2000 ／ 横版 1920×1080）：

   ```python
   import pypdfium2 as pdfium
   pdf = pdfium.PdfDocument("poster.pdf")
   page = pdf[0]
   page.render(scale=96/72).to_pil().save("poster.png")
   ```

4. **不要用 poppler / pdftoppm**——会把"系统级安装依赖"变成一个新的环境变量。

## 3. 禁令

- **交互截图路径（`--screenshot`）不得用于定稿导出**。前期严寒探针实测：字体时序不稳 → 面板 -22px、底栏出画、视口 1913 ≠ 2000，且两次渲染结果不一致（不可复现）。截图只可用于"看一眼草稿"，**不作为交付路径**。

## 4. 字体守卫

- 打印前**等待 `document.fonts.ready`**（`await document.fonts.ready`），否则 PDF 可能落在字体加载完成之前，用回退字体渲染。
- 字体链见 layout-composition.md §4.6（写死的中文 / 英文字体链，命中即用）。
- **交付说明披露实际渲染字体**；验收记录留一行。

## 5. 稳定性断言（定稿必跑）

- **同一 PDF 两次独立渲染，像素 diff = 0**（逐像素比对即可）。实测值写入验收记录。
- **布局自报**：页内脚本输出每个文字块的 `scrollHeight / clientHeight / lastBottom`，断言"无溢出、内容外边界落在长边 95%–99% 的预算内"（竖版底边 1900–1980 @1600×2000 ／ 横版右边 1824–1900 @1920×1080）。**换字体引起的行高 / 字宽漂移会在这里当场暴露**，而不是静默崩版。
- **导出尺寸断言**：PNG 尺寸必须精确等于所选取向的基准（竖版 1600×2000 = 4:5 ／ 横版 1920×1080 = 16:9）。

## 6. 适用范围

- 本规范对**全部执行环境档位**生效（见 SKILL.md 第 0 节）。
  - **全功能 / 半功能档**：执行者本地跑完整链路。
  - **纯对话档（网页版）**：本规范的脚本与断言随包交付，**由用户在本地执行**，断言结果回填验收记录。
- "两次渲染 diff = 0" 是**通用断言，不锁死具体工具**：Mac / Linux 用等价工具链，只要过断言就算合规。
