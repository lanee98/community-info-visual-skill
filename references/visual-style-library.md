# 视觉风格库

从 validated 视觉参考中归纳的风格档案。选风格时按**信息调性（应急警示 / 服务告知）+ 传播目标 + 受众构成**匹配，并按 SKILL.md 第 3 步写出一句话理由。所有风格都必须通过可读性规范，风格库只决定"好看的方向"，不豁免"看得清"。

> 风格管"皮肤"，骨架管"骨骼"：选完风格后必须到 [排版与可读性规范](layout-composition.md) 选定版面骨架 B1–B10，两者组合才算方案成立。

## S1 单色警示系统（来源：馒头山社区导视）

- **配方**：灰阶摄影/灰阶场景底 + 唯一高饱和强调色（参考例用柠檬黄）+ 有机形状图标家族 + 粗壮无衬线字体。强调色只给信息（图标、关键路径、重点词），灰底做层。
- **优点**：识别速度极快，单色系统天然高对比；图标可扩展成家族（同一形状语言做全套服务图标）。
- **适用**：警示、导视、"找地点"类。社区服务信息的最稳底牌。
- **要点**：强调色全图只此一种；图标形状保持"手作感/有机感"时也必须内外统一描边逻辑。

## S2 地图导视系统（来源：馒头山社区地图）

- **配方**：浅灰底 + 灰色肌理块（建筑/绿化抽象）+ 单色服务线路 + 编号圆点 + 底部图例表。中英双语对照图例。
- **适用**：服务点分布、 "去哪里"型信息；常作为 S1/S4 的内嵌模块（海报局部放服务点小地图）。
- **要点**：编号与图例一一对应；服务点用强调色圆点放大突出；地图简化度优先于精度——居民不需要比例尺，需要"从哪走到哪"。

## S3 报刊编辑风（来源：灰色报刊版式）

- **配方**：高灰度层级（纸白+浅灰+深灰）+ 超大号标题（可竖排）+ 细栏正文 + 灰度图片。
- **适用**：文字量大的公告、通知、政策解读。是六种中唯一能承载 L3 大段文字的风格。
- **要点**：标题字号极端放大补偿低装饰性；正文灰度不低于 70% 黑；低彩色度下必须靠字号层级拉开节奏，否则整版发闷。**应急警示不选此风格**（警示感弱）。

## S4 高饱和贴纸系统（来源：夏日清凉系列）

- **配方**：高饱和双色渐变底（如蓝→青，对应"清凉"语义）+ 白描边贴纸徽章（圆角标签、箭头、爆炸框）+ 波浪/几何辅助图形 + 可爱 IP 元素（笑脸、拟物）。
- **优点**：亲和力强，适合社区、家庭向受众；贴纸系统天然适合"服务点/开放时间/电话"这类卡片信息；主题语义可与配色呼应（高温=清凉蓝）。
- **适用**：常规服务告知、活动通知、清凉服务点。老年受众为主时可保留其高对比，去掉过小过密的贴纸装饰。
- **要点**：贴纸内文字必须后制排版；装饰贴纸密度控制在 L1 层干净的前提下；笑脸类 IP 不用于哀伤/严肃主题（疾病、事故）。

## S5 点阵/细线图示（来源：须臾之痕植物生长记录）

- **配方**：白/浅底 + 细线点阵插画 + 单一强调色块（参考例用青色）+ 大量留白 + 中英双语小标签。
- **适用**：分步指南、动作示范（七步洗手法、防暑动作）、生长/过程记录类科普。
- **要点**：细线风格在小尺寸会消失——线条最细处按最终输出的 ≥ 2px 校验；步骤编号明显；留白多意味着层级容错低，字号与对比度必须严格达标。

## S6 等轴测信息图（来源：GVI 绿视率研究图示 / HHRI 综述图；进阶范式：多层场景+引线标注+数据角）

- **配方**：扁平等轴测场景 + 图标化元素 + 分类框 + 箭头流程；科研综述可用环形/放射结构 + 柔和学术配色。
- **适用**：原理解释、系统关系、多要素分类科普；也适合海报中的"数据角"。
- **要点**：学术风信息密度高，上海报必须裁剪——只保留居民需要的分支；等轴测小元素多，注意最小字号与元素间距；柔和学生配色对比度不足时加深文字色。
- **进阶模块（来自"社会恐惧症"级参考，适合 D2–D3 科普长图）**：
  - **多层平台**：2–4 块不同高度的等轴测平台上下错落，平台高度差即视线动线（先看哪、后看哪由高度排布决定）；平台间用台阶/楼梯元素衔接。
  - **引线标注系统**：场景中的关键元素用**点线 + 端点圆点**连到统一注释列（图标头 + 短标签 + 两行说明）；引线不交叉、不过文字；注释列与场景等高起步、逐条对齐。
  - **数据角**：底部紧凑放 1–2 个图表（条形/环形）+ 一张清单卡；图表用同一强调色系，**数据必须来自母本，不许为了好看编造数字或让 AI 自由发挥图形数据**。

## S7 手绘社区插画叙事（来源：社区健康讲座招募双联海报）

- **配方**：暖色纸感浅底 + 场景化人物插画（人物演出真实活动动作）+ 色块标签分段文字 + 圆角信息卡。插画是叙事者不是背景。
- **优点**：亲和力最强、最有"社区温度"；插画能形象化提醒（画什么动作 = 提倡什么行为）；图文穿插天然带空气感。
- **适用**：活动招募、健康讲座、亲子/养老服务告知；D1–D2 密度。与骨架 B2 插画叙事型配套。
- **要点**：插画按 layout-composition.md §3 规程生成（人物动作对应真实信息、留白前置、无文字无水印）；插画风格全海报统一；正文对比度不许因纸感底而降档。**严肃警示主题不选**（亲和感会削弱警示力）。

## S8 拼图色块系统（来源：万科社区年度系列海报）

- **配方**：2–3 色大圆角色块拼图式咬合分割版面 + 超大关键词（每张只讲一个词）+ 小号注释文字形成极端大小对比 + 照片/插画嵌在色块缺口 + 中英双语小标签。
- **优点**：大小对比教科书，3 秒锚点极强；天然适合系列化（多张统一模板换词换图）。
- **适用**：系列传播、年度盘点、成果展示；D1–D2。与骨架 B3 配套。
- **要点**：数字必须超大处理（1350 场、26215 场式）；色块 ≤ 4 色；注释文字虽小仍须达标对比度；每张海报信息量克制——它天生是 D1 风格，硬塞 D3 内容会毁掉对比。

## S9 手账网格杂志风（来源：龙湖超级社区体验季系列）

- **配方**：纸质感浅底 + 手绘涂鸦元素（箭头、胶带、贴纸、描边图标）+ 网格卡片分区 + 标题拼贴混排（大字+手写体+括号强调）+ 编号 ①②③ 挂卡。
- **优点**：信息多而不公文、亲切不严肃；网格给高密度内容天然的呼吸感结构。
- **适用**：多板块活动预告、权益清单、招募说明；D2–D3。与骨架 B4 配套。
- **要点**：手绘元素同一套线条语言，每页涂鸦 ≤ 8 个（是路标不是噪音）；编号视觉明显；网格卡片内部仍按层级排。

## S10 图形化数据叙事（来源：向涛社区"治理密码"展板）

- **配方**：大号数字色块承载体系（1/3/4/5 放大到 80pt+）+ 胶片条/丝带形照片带分区 + 三段式标题系统（主标/副标/导语框）+ 页面序号。
- **优点**：体系感与权威感强；数字即视觉主角，数据一目了然。
- **适用**：工作汇报展板、成果数据展示、体系解读；D2–D3。与骨架 B5 配套。
- **要点**：照片带统一裁切高度；每段说明 ≤ 3 行；数字色块颜色与全图色系统一；它是"汇报向"风格，居民服务告知慎选（叙事视角是社区而不是居民）。

## S11 全景多景叙事（来源：企业社会责任报告全景主视觉）

- **配方**：**一幅连续的插画世界**铺满主视觉区（**≥65% 版面**）——建筑、蜿蜒道路/河流等"连接元素"把 4–7 个活动小景串成一个完整世界；每个小景演出信息清单里的一条真实行为（太极、搀扶、轮照护、锻炼……）。标题带压在天空/浅色留白区，信息条收在底部。
- **色彩三层次（本风格的生命线）**：大面积低饱和底（草地、天空）→ 中面积中饱和（建筑、树木、路径）→ 小面积高饱和强调（人物衣物、花朵、关键词）。全图色相控制在相邻色系（如绿–青）+ 至多一个暖强调色。
- **纹理填充层**：小花、云朵、飞鸟等低干扰小元素填充空隙——同一套形状语言、≤ 一层、密度以"不遮掩任何人物动作轮廓"为上限。
- **适用**：D1–D2；社区形象、服务全景、年度主题、亲和向告知。常作 B1 骨架的主视觉，也可近乎整幅即海报。
- **要点**：
  - 小景必须逐个指回信息条目（三问规程照用）——"看着热闹但说不出在演哪条信息"的景是装饰，删。
  - 路径有起点有终点：起点引导视线入场，终点或中心放主题物（服务点、社区地标、主题装置）。
  - 人物是"生活的连续瞬间"，不做同一动作复制；人群构成与受众对应（按主题画出对应人群：老人、儿童、户外工作者等）。
  - 生图用七槽位模板（layout-composition.md §3.2），把"多景+路径+纹理层"写进场景与构图槽位；成图后逐景核对信息指涉。

## 慎用风格（默认不选）

- **热成像/故障 glitch 艺术风**：视觉冲击强但信息可读性差、色彩语义混乱，公共服务信息默认不用；仅当用户明确要求艺术化表达时使用，且信息层另行保证可读。
- **深底荧光字 / 低对比渐变文字**：违反对比度硬条款。
- **密集拼贴渲染风**（愿景展示类）：信息密度失控，居民抓不到重点；除非用户要求，不用于服务信息。

## 风格组合建议

一张海报常用"主风格 + 内嵌模块"：例如 S7 插画叙事为主体 + 顶部 S1 式高对比预警条 + 底部 S2 式服务点列表。组合时所有模块共用同一强调色系与同一图标语言，否则退回单风格。骨架组合规则见 layout-composition.md §2（骨架可复合，如 B1 主视觉主导 + B4 网格卡片）。
