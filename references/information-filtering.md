# 信息筛选与密度分级

> 回答两个问题：**母本不是设计清单**（把母本全部堆上海报 = 没有设计）；
> **筛选标准是"这条信息能不能让居民做对事"** —— 服务行动则留，不服务则压缩或舍弃。
> 本文件规定"删什么、留什么、怎么压缩"，以及信息多/信息少两种局面各自的打法。

## 0. 筛选的立场（先立心，再动手）

- 母本是**事实来源**，不是**上版清单**。上版内容是筛选后的产物。
- 每张海报只有一个主任务：**让居民据此做对事** —— 知道该注意什么、该做什么、去哪里办、何时求助。
- 判断任何一条信息时先问："**它服务于这个主任务吗？**" 服务则留，不服务则压缩或舍弃——**哪怕它在母本里印得很长很正式**。
- 海报是 3 秒媒介，不是文件公告栏。受众停留不超过 30 秒——按 30 秒能读完的量倒推上版字数。

## 1. 筛选标准：看"要不要据此行动"

| 裁定 | 含义 | 典型对象 |
| --- | --- | --- |
| **锁定上版** | 逐字呈现，最大保护 | 时间、地点、电话、核心行动条目、标题、机构名 |
| **压缩上版** | 一段话 → 一句话 + 加粗关键词 | 背景陈述、政策依据、防护说明 |
| **指针化** | 正文不展开，用二维码 / "详见社区公告栏" / 咨询电话替代 | 报名流程、完整条款、多页细则 |
| **舍弃** | 不上版，进"未上版信息清单" | 与传播目标无关的套话、纯内部流程描述 |

三条判定问句（逐条自问）：
1. 删掉这条，居民会做错事或白跑一趟吗？——会 → 锁定；不会 → 继续问。
2. 这条是"行动"还是"陈述"？——陈述 → 压缩成一句或舍弃。
3. 这条在别的渠道（二维码、公众号、现场工作人员）能拿到吗？——能 → 指针化。

### 1.1 通用红线

- **L1 识别层、L2 行动层的锁定信息永远不可裁定为舍弃**。发现"信息放不下"时，正确动作是继续筛 L3、或回版式（见 layout-composition.md）调整骨架，**而不是压缩电话号码、时间或地点的字号**。
- 母本条目数与上版条目数不一致时，差异必须逐条可追溯（哪条压缩了、哪条指针化了）。

## 2. 信息超量时的取舍优先级（D3 专用）

老师给的资料"过多"是常态。当筛完仍 > 10 块（D3）时，按下列**固定优先级**从低到高砍，砍到 ≤ 10 块为止：

| 优先级 | 信息类型 | 处理动作 |
| --- | --- | --- |
| 1（最先砍） | 背景介绍、意义陈述、领导讲话要点、政策原文 | 舍弃或压成一句 |
| 2 | 流程细则、条款、多步骤办事说明 | 指针化（二维码/指引） |
| 3 | 同质重复条目（5 个服务点、8 条注意事项） | **合并**：表格 / 地图模块 / 图标清单 |
| 4 | 次要时间地点（非主会场的分组信息） | 压缩为一行小字或指针化 |
| 5 | 长句中的修饰与铺陈 | 保留"关键词"，删修饰语（不改事实） |
| 6（最后才动） | 锁定信息（时间/地点/电话/名称/核心行动） | **只允许合并呈现，不允许删减或缩小到不合规** |

- **合并是压缩的合法手段，也是首选手段之一**：服务点用表格或小地图（S2）、注意事项用图标+短句清单，替代逐条大段排版。
- **四轮筛完仍超量**：才与用户商量——砍 L3 边缘信息，或改为系列海报 / 双面 / 折页。**不许用缩小字号来"解决"超量**，那是把"放不下"转嫁给"看不清"。

## 3. 密度分级（D 级判定）

筛选完成后数一遍上版内容块（一个不可拆的信息单元 = 1 块，如"一个服务点 = 名称+地址+时间"算 1 块）：

| 级别 | 内容块数 | 局面 | 主策略 |
| --- | --- | --- | --- |
| **D1 低密度** | ≤ 5 | 信息少，版面空 | 补内容 + 大版面分割（见 §5） |
| **D2 中密度** | 6–10 | 常规 | 标准层级排版，主视觉区照常保留 |
| **D3 高密度** | > 10 | 信息超量，塞不下 | 先删后排（见 §2），**先筛到 ≤ 10 块再谈排版** |

## 4. D3 高密度排版要点

- L3 详情层允许整块"降级呈现"：小一号字、灰度降一档、收进底部条带——但对比度仍须达标（见 readability-and-elderly.md），降级不等于作弊。
- 长句必须完成"提取"再上版：一句原文 → **加粗关键词（图形化放大）+ 常规字说明**。例："活动当日请携带身份证原件前往二楼登记" → **带身份证原件** / 二楼登记。
- 高密度版面更要留呼吸感：块间距 ≥ 字高的 0.8 倍，分区之间用色带或留白隔开，不许两块文字贴着排。

## 5. D1 低密度打法（信息少 ≠ 随便排）

信息少时最常见的失败是"内容孤零零吊在中间，四周全是空白"。三条路，通常组合使用：

### 5.1 补充内容（补"有用"，不补"凑数"）

**先分清两种"补"——语言扩写 ≠ 事实编造**：

| | 语言扩写（允许，经确认） | 事实编造（禁止） |
| --- | --- | --- |
| 定义 | 把母本短句展开成更完整自然的表达，**不新增任何事实** | 增加母本没有的电话、名称、时间、数量、机构 |
| 例子 | "减少出门" → "高温期间请减少不必要的外出活动" | 母本没给咨询电话，自己写一个 0731-XXXXXXX 充数 |
| 判据 | 扩写前后事实集合相同，只是更易懂 | 扩写后多了可被当真的具体信息 |
| 流程 | 扩写稿列入确认门 ① 的事实核对单，用户确认后才锁定 | 任何情况下都不进图；缺失事实用 `【待确认】` 占位并向用户索要 |

**应急警示型补法**：
- 补行动细节（第一步是什么、做完之后呢）
- 补场景提示（什么人最需要关注）做一条"特别提醒"
- 补后果/收益（做到会怎样、不做会怎样）一句话图形化
- 补时间轴/流程（一件事拆成 1→2→3 步骤图示）
- 对母本短句做**语言扩写**（如上表），让单薄条目变得完整可读

**服务告知型补法**：
- 放大主视觉/插画（D1 时 **≥ 65%**）——信息少时"图形当内容用"，把主题场景画足，复杂度按 layout-composition.md §3.0 执行
- 补服务细节（服务点位、时段、可办事项展开成"服务 1/2/3"）——只展开母本已有的信息，不新增事实
- 补办事路径（怎么去、带什么、找谁）
- 补图示说明（分步图示、位置示意）

- **红线**：事实编造绝对禁止（见上表）。语言扩写与一切新增内容须经确认门 ① 用户确认后才能进入锁定母本；确认前按 `【待确认】` 占位处理。

### 5.2 大版面分割（版面当内容用）

- 低密度版面的正确形态是**大面积分区**：主视觉区 ≥ 65%，信息区做成 2–3 个大块，每块内部留白充足。
- 用"图片区 / 大标题区 / 信息卡区 / 页脚区"把 4:5 画布切出明确的几何结构，而不是让一条信息居中漂浮。
- 插画/意象在这个局面下价值最大：既填充版面，又形象化地传达主题（见 layout-composition.md §3）——**插画面积大了，复杂度标准不降反升**（§3.0），"信息少所以画简单点"是本末倒置。

### 5.3 字号放大不是万能解药

- 信息少时可放大标题与关键信息，但**不要用"把所有字放大一倍"填版面**——层级对比会被抹平。放大应集中在名称、关键数字、行动动词上，制造大小戏剧性。

## 6. 与其他文件的关系

- 筛定后的内容结构 → 交给 [版式构成与插画指令](layout-composition.md) 选骨架。
- 锁定信息的核对规则 → [信息准确性与母本核对](information-accuracy.md) 不变，核对范围 = **筛选后实际上版的内容** + 未上版清单复核。
- 字号对比度底线 → [可读性与适老化规范](readability-and-elderly.md) 永远不因密度让步。
